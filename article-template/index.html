How to save a webpage as PDF in Chrome

The fastest way is the Download webpage as PDF extension. It keeps the page exactly as you see it, as one long PDF page with selectable text.

Install the extension

  1. Open the extension page in the Chrome Web Store
    Go to Download webpage as PDF in the Chrome Web Store and click Add to Chrome.
  2. Confirm the installation
    In the dialog, click Add extension.
    The icon appears under Extensions in the Chrome toolbar.
  3. Pin it for one-click access
    Click Extensions, then the pin next to Download webpage as PDF.
    The icon stays next to the address bar.

Save the page as PDF

  1. Open the page and let it load fully
    Scroll to the end once so lazy-loaded images appear.
  2. Click the extension icon and choose Download as PDF
    A PDF with the whole page downloads to your Downloads folder.

Choose page size and orientation

Before saving, open Settings in the extension popup:

  • One page keeps the page continuous, best for reading on screen.
  • A4 or Letter splits the page into printable sheets without cutting images.
  • Portrait or landscape fits wide tables and dashboards.

Add highlights, notes and arrows

Pick a tool in the toolbar at the top of the editor, then click or drag on the page.

  • Highlight marks text in yellow; switch to Underline or Strikethrough in the same menu.
  • Text adds a note anywhere on the page.
  • Arrow and Rectangle point to exactly where you mean.
  • Pencil draws freehand; Eraser removes any annotation.

How to print a PDF with annotations

  1. Open the annotated PDF in Annotate PDF.
  2. Click Print in the top right corner.
  3. In the Chrome print dialog, set Destination to your printer and open More settings.
  4. Make sure Background graphics is on, otherwise highlights may not print.
  5. Click Print.

Tip. Printing a long one-page PDF? Save it as A4 first in the extension settings so nothing is scaled down to a tiny strip.

Working with a scanned PDF or text you can't select

A scanned PDF is a picture of a page, so there's no text to select. You can still annotate it: use Rectangle or Pencil instead of Highlight, and add notes with Text.

Pages saved with Download webpage as PDF always keep real, selectable text. Only scans and photos of documents behave like images.

Common problems and how to fix them

The PDF won't let me add annotations
Cause
The file is password-protected or restricts editing.
Fix
Ask the sender for an unrestricted copy, or save the original webpage again with the extension.
I can't select anything on the page
Cause
A view-only tool is active, or the PDF is a scan.
Fix
Pick Highlight or Select in the toolbar. For scans, see scanned PDFs.
My annotations disappeared after saving
Cause
The tab was closed before Export finished, or you opened the original file.
Fix
Export again and open the newest file in Downloads.
Saving takes a long time
Cause
Very long pages with many images or infinite scroll.
Fix
Wait for the progress bar to finish; for infinite feeds, scroll only as far as you need before saving.
