How to remove the last page from a PDF

To remove last page from PDF, work on a copy, select the final page thumbnail in Preview or Acrobat, delete it, and save. If you only need a static reading copy, Chrome can save a retained range instead: for an eight-page document, keep pages 1–7.

Check the new ending before sharing. An apparently blank final sheet may still contain a footnote or signature. A PDF file must retain at least one page for the methods below; deleting its only page is not a useful way to create an empty document.

Choose a method for your PDF

For PDF files with several unwanted pages, these instructions still target only the final sheet.

Method Best use Main limitation
Preview on Mac Delete the final thumbnail from an existing document Check restrictions and save a separate copy
Acrobat desktop Direct page deletion with page-organizing tools Requires access to those tools and an editable document
Chrome on Windows Create a new copy containing only the retained range Printing may change layout or interactive behavior

Use direct page removal when forms, bookmarks, or internal links matter. A printed replacement is a different operation, so inspect any features you rely on afterward.

On a Mac: delete the last page in Preview

  1. Open the PDF file in Preview.
  2. Choose File > Duplicate to preserve a backup copy of the original.
  3. Choose View > Thumbnails.
  4. Select the final thumbnail in the sidebar. Preview can select several unwanted pages; keep only the last thumbnail selected.
  5. Press Delete, or choose Edit > Delete.
  6. Choose File > Save, give the copy a distinct name, and save it as a PDF.

Apple documents both deleting PDF pages and duplicating a document. Annotations on the deleted page are removed with it.

Look at the thumbnail’s position, not just the page numbers printed inside the document. A cover or Roman-numbered introduction can make those labels differ from the file’s physical sequence. After saving, reopen the copy and check that an eight-page original now has seven pages.

In Acrobat: remove the final thumbnail

Open the PDF file in Acrobat and choose All tools > Organize pages. Locate the last thumbnail, select its Delete action, and confirm the deletion. Save the result under a new filename so you can recover the original if necessary.

Adobe’s page-deletion instructions also support selecting page positions or ranges. For one unwanted ending, selecting its thumbnail is easier to verify than entering a range. Do not select additional unwanted pages unless you intend to remove them too.

If you cannot delete PDF pages, check File > Document Properties > Security for restrictions. A password protected PDF may require permission to edit even if you can open and read it. Ask the document owner for an editable copy when necessary. Do not assume that the free Reader has the same page-organizing functionality as Acrobat.

Digitally signed PDF files need particular care. If someone else signed the document, request an unsigned original rather than assuming page deletion will preserve the signature. Adobe explains these signed-document restrictions.

On Windows: save only the pages you want to keep

For ordinary PDF files, Chrome provides a local alternative that creates a new printed copy:

  1. Open the PDF file in Chrome and check its total page count.
  2. Press Ctrl+P.
  3. Set Destination to Save as PDF.
  4. Under Pages, choose Custom and enter the retained range. For eight pages, enter 1-7. For two pages, enter 1.
  5. Inspect the preview, including the new final page and any wide content.
  6. Click Save, choose a new filename, and reopen the result.

The range identifies the correct pages to keep, not those to delete. Entering only 8 saves the eighth page—the opposite of the intended result. Use actual page numbers, not last or the literal expression N-1.

Google’s Chrome printing guide documents opening files, selecting a destination, and saving to PDF. This route does not modify the original PDF file in place.

Printing can affect page dimensions and document features. Do not assume a replacement retains editable forms, bookmarks, accessibility structure, or signature validity. Direct editing is preferable for feature-rich PDF files, subject to their permissions. Neither route guarantees that internal links pointing to deleted content will remain useful.

If the PDF was just created from a webpage

For an eligible multipage result still open in Download webpage as PDF, you can remove the trailing sheet before downloading:

  1. Click the scissors control labeled Trim pages.
  2. Select the gap immediately before the last page.
  3. Verify that only the final page is marked for removal, then click Trim.
  4. Check the result and click Download.

The Download button saves the document currently shown. Undo trim can restore the stored original during the eligible active session. Check your selection before returning to the Download button.

This feature removes all pages after the chosen boundary. It is not an uploader for arbitrary PDF files or a tool for deleting selected middle pages. Controls are conditional; history views and some recovered results do not offer trimming. Trim bottom on a single long page is a different operation from deleting a whole trailing sheet.

Check the saved copy

Verify the updated PDF, not just its filename:

  • The page count has decreased by exactly one.
  • The first page is unchanged and the correct pages remain in order.
  • The new ending contains the expected final paragraph, image, or table.
  • Important bookmarks, forms, links, and annotations still work where needed.

Page numbers printed within the document may not renumber themselves after page removal. Keep the original until the updated PDF passes your checks.

Frequently asked questions

Why is deletion unavailable?

Check whether the tool can delete PDF pages, whether the document has more than one page, and whether editing is permitted. For a password protected PDF or a locked signed document, ask the document owner for an editable original. Printing is not a promise of bypassing restrictions.

Can I undo the change?

Before closing the editor, its Undo command may reverse the operation. Afterward, your backup copy is the dependable recovery option. If you remove last page from PDF and later discover that it contained essential information, restore the original and repeat the edit with the intended selection.

Can I delete PDF pages without uploading them?

Yes. Preview, Acrobat desktop, and Chrome’s local saving route can handle an existing file on your computer. Choose the method that fits your document, then check that the unwanted pages are absent from the new copy. No online upload is needed for these instructions.
